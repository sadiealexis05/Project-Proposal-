# Revisiting Higher-Order Masked Comparison for Lattice-Based Cryptography: Algorithms and Bit-sliced Implementations 

Group Members: Teagan Hawkins, Jackie Medrano, Sadie Salcido

Overview:
Revisiting Higher-Order Masked Comparison for Lattice-Based Cryptography: Algorithms and Bit-sliced Implementations is a paper where researchers set out to optimize the masked comparison step within the Fujisaki-Okamoto (FO). Rather than designing entirely new cryptographic algorithms, they introduced new mathematical techniques and software optimizations such as bit-slicing implementations to make this comparison faster at higher masking orders. They evaluated these optimizations by implementing and benchmarking them using existing lattice-based schemes, Kyber and Saber, on an ARM Cortex-M4 microcontroller.
